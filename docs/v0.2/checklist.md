# HorizonCode — Checklist v0.2：工具系统

## 工具契约与注册

- [ ] `rg "class BaseTool" horizoncode/tools` 至少返回 1 个统一工具抽象定义，且公开类和公开方法有中文 docstring。
- [ ] 默认注册中心恰好包含 6 个名称不同的核心工具：读文件、写文件、改文件、执行命令、按模式找文件、搜代码内容。
- [ ] 任一核心工具的声明包含非空名称、描述和 JSON Schema；Anthropic 与 OpenAI 导出的六个工具名称集合完全相同。
- [ ] 注册重复工具名称时得到结构化或明确的重复名称错误，不会静默覆盖。
- [ ] 所有工具结果都能序列化为 JSON 对象，至少含 `ok`、工具名和结果/错误字段。

## 项目路径与文件工具

- [ ] 从项目内读取 `horizoncode/history.py` 成功，结果路径为相对项目根目录的路径。
- [ ] 读取 `../outside.txt`、绝对路径和经符号链接逃逸到项目外的路径均返回 `path_outside_workspace`，且没有读取项目外内容。
- [ ] 读取目录或包含 NUL 字节的文件返回结构化失败，程序不崩溃。
- [ ] 单次读文件默认最多返回 1 MiB 文本；超过上限的结果标有 `truncated: true`。
- [ ] `write_file` 向已有项目内文件写入新文本后，文件内容与输入完全一致；父目录不存在时返回 `not_found`，不创建目录。
- [ ] `edit_file` 对唯一出现的原文执行一次替换，替换后文件仅有该处变化。
- [ ] `edit_file` 的原文不存在时返回 `match_not_found`；原文出现两次时返回 `match_not_unique`；两种失败下文件内容保持不变。

## 搜索工具

- [ ] glob `horizoncode/**/*.py` 仅返回项目内文件，结果按字典序稳定排列。
- [ ] glob `../**/*` 或绝对模式返回路径边界错误，不泄露项目外文件名。
- [ ] 文本搜索 `stream_chat` 返回至少两个命中，每个命中含相对路径、正整数行号和对应行文本。
- [ ] 正则搜索能返回命中；无效正则返回 `invalid_arguments`，无匹配返回成功且空命中列表。
- [ ] glob 和内容搜索默认最多返回 100 个结果；达到上限时结果标有 `truncated: true`。

## 命令工具

- [ ] 命令请求显示完整命令、固定项目工作目录和默认 30 秒超时，并在用户明确确认前不启动进程。
- [ ] 用户拒绝后结果为 `denied`，且 mock 子进程断言未被调用。
- [ ] 确认执行的 `uv run python -c "print('ok')"` 返回退出码 `0` 与 stdout `ok`。
- [ ] 返回非零退出码的命令仍产生成功完成的工具结果，结果含退出码、stdout 和 stderr，而不是使 TUI 崩溃。
- [ ] 超过 30 秒的命令被终止并返回 `timeout`；标准输出和标准错误各最多保留 20,000 个字符，并标明截断状态。
- [ ] 工具调用不能通过参数改变工作目录或指定不同 shell。

## Provider 与历史

- [ ] OpenAI mock SSE 中同一 `tool_calls` 参数分三段到达后，Provider 只产出一个完整调用，参数 JSON 可被正确解析。
- [ ] Anthropic mock SSE 中工具输入 JSON 分片到达后，在内容块结束时只产出一个完整调用，参数 JSON 可被正确解析。
- [ ] 两个 Provider 发出的请求都包含六个工具声明，同时原有纯文本流测试继续通过。
- [ ] 流中两个关联 ID 不同的工具调用均被保留，名称、参数和关联 ID 不混淆。
- [ ] 运行工具后，会话 JSON 同时保存 assistant 工具调用和对应工具结果；重新加载该 JSON 不丢失关联 ID。
- [ ] 下一次请求生成的 Anthropic 消息含正确匹配的 tool-use/tool-result 内容块；OpenAI 消息含 assistant `tool_calls` 和 role 为 `tool` 的结果消息。

## TUI 编排与端到端

- [ ] 一次 mock 模型响应包含 `glob_files` 和 `read_file` 两个完整调用时，TUI 按响应顺序执行两者，并在终端展示两个结果摘要。
- [ ] 上述两调用的结果写入历史后，断言该用户轮次仅发生一次 Provider 请求；TUI 回到输入提示，未自动请求模型第二次。
- [ ] 一次响应同时含命令与非命令工具时，非命令工具直接执行，命令工具仅在用户确认后执行；拒绝命令不会阻止其他独立调用结果被记录。
- [ ] 用户在工具参数尚未形成完整 JSON 时中断流，TUI 不执行该不完整工具调用。
- [ ] `uv run pytest` 全部通过。
- [ ] 在临时项目目录中启动 HorizonCode，使用支持工具调用的任一 Provider 发出“列出 Python 文件并读取 `horizoncode/history.py`”请求；终端显示两个工具结果，随后输入一次追问时 Provider 请求历史含前一轮工具结果，且在未再次提问前没有自动追加模型回复。
